# 예제: 라이너 IR 덱 → 시스템 프롬프트

한 덱을 분석해 §1~§10을 어떻게 채우는지 보여주는 압축 예제다. 실제 산출물은 각 섹션이 더 길다. 여기 값은 예시일 뿐, 다른 덱에 그대로 복사하지 않는다.

## 입력

```
@~/Desktop/LINER/[IR Pitch Deck] Liner KR.pdf 이걸로 프롬프트 만들어줘
```

## 추출 요약 (분석 단계 산출)

| 항목 | 관찰값 |
|---|---|
| 슬라이드 비율 | 16:9 |
| 색상 | 8개 (--forest-dark #0B5A3C, --lime-accent #C4D96F, --lime-pale #E8F0BF …) |
| 폰트 | Apple SD Gothic Neo 계열, 숫자는 mono |
| 기본 패딩 | 6cqi 7cqi 8cqi |
| 등장 레이아웃 | 5종 (표지, 섹션+카드, 비교 테이블, 막대 차트, 마무리) |
| 종결 표현 | "~합니다" 우세 |
| 숫자 표기 | 천 단위 콤마, 소수 1자리, 단위 붙여쓰기 |

## §1~§10 채움 (발췌)

```
## §1. 역할과 기본 규격
너는 라이너 IR 덱과 동일한 시각 언어로 새 슬라이드를 만드는 디자이너다.
형식 미지정 시 16:9 단일 HTML 덱을 만든다.

## §2. 디자인 시스템
--forest-dark: #0B5A3C;  /* 표지 배경, 메인 캔버스 */
--lime-accent: #C4D96F;  /* 키워드 강조, 강조 배경 */
--lime-pale:   #E8F0BF;  /* 보조 강조, 테이블 헤더 */
--ink:         #000000;  /* 본문 */
--muted:       #666666;  /* 메타, 날짜 */
--line:        #E0E0E0;  /* 테두리 */
--highlight:   #D4472A;  /* 비교 우위 강조 */
(타이포·그리드·데코 표 이어짐)

## §3. 슬라이드 레이아웃 카탈로그
### 레이아웃 1: 표지 — 회사명·로고 중앙, 좌하단 날짜, 우하단 기밀 표기
### 레이아웃 2: 섹션+카드 — 좌측 섹션 라벨, 우측 카드 2~3개
### 레이아웃 3: 비교 테이블 — 자사 열 강조(빨간 테두리)
### 레이아웃 4: 막대 차트 — 자사 forest-dark, 경쟁사 회색
### 레이아웃 5: 마무리 — 핵심 메시지 + 다음 단계 3개
(이 덱엔 5종만 등장했으므로 5종만 기록)

## §5. 한국어 표기 원칙
- em dash 0개, 괄호·콜론으로 대체
- 종결 "~합니다" 통일
...

## §6. 숫자·단위·약어
- 천 단위 콤마(1,420), 소수 1자리(+12.3%)
- 단위 붙여쓰기(50ms, 2.4x), 통화 앞(₩1,200)
...

## §10. 품질 체크리스트
- [ ] 색은 §2 토큰만 사용
- [ ] 종결 "~합니다" 통일
- [ ] em dash 0개
...
```

## 보고 (사용자에게)

```
완료. 라이너 IR 덱을 분석했습니다.

- 색상: 8개 (--forest-dark, --lime-accent 등)
- 레이아웃: 5종 (표지, 섹션+카드, 비교표, 차트, 마무리)
- 콘텐츠: 천 단위 콤마, "합니다" 종결, IR 톤

파일: ~/Desktop/[IR Pitch Deck] Liner KR-prompt.md (17KB)
```

## 이 예제가 보여주는 것

- 레이아웃을 억지로 9개 채우지 않았다. 덱에 5종만 있으면 5종만 쓴다.
- 색은 이름이 아니라 hex로 고정했다.
- 각 섹션에 복제 가능한 구체 값이 들어갔다.
